# Køge Guesthouse & Roskilde B&B — design 3

Static design preview for owner review.

- [Køge Guesthouse — dansk](koege/da/index.html) · [English](koege/index.html)
- [Roskilde B&B — dansk](roskilde/da/index.html) · [English](roskilde/index.html)

Use the property selector at the top of any page to switch between the two.

**Roskilde, design 04 "Sunset"** — [roskilde-sunset/index.html](roskilde-sunset/index.html): a modernised
version of the original roskildebnb.dk design that keeps the original page text verbatim (English and
Danish side by side, as on the current site). The "Design" bar at the top of every page (Køge too; 04/05 exist only for Roskilde)
switches between v3, 04 and 05 on the same topic. Fonts for 04: [Strait](https://fonts.google.com/specimen/Strait)
and [Source Serif 4](https://fonts.google.com/specimen/Source+Serif+4), licences alongside.
Map and videos on 04 load from Google/YouTube only when clicked.

**Roskilde, design 05 "Mix"**: [roskilde-mix/index.html](roskilde-mix/index.html): v3's compact layout with
04's original text and look. Booking comes first: a booking box at the top of every page (so visitors can
book from whichever page they land on), a "Book now" button in the header and a Book/Call bar on phones.
Larger text and buttons. Booking is switched off in this preview: dates can be chosen, but nothing is sent.
Both have nine pages in Danish and English. The website runs without a backend or build step.

Booking controls are intentionally disabled. This is a design preview, not a booking service.
The existing business websites are unchanged. Search indexing is discouraged using robots
directives; this preview is public and the directives are not access protection.

Only static HTML, CSS, JavaScript, public website images and locally bundled fonts are included.
No hosting configuration, backups, databases, API keys, credentials, or earlier project history
are included. Image derivatives do not retain EXIF metadata.

Typography: [Newsreader](https://fonts.google.com/specimen/Newsreader) and
[DM Sans](https://fonts.google.com/specimen/DM+Sans). Their SIL Open Font Licenses are included
alongside the local fonts. Property photographs and original review screenshots remain
the property of their respective rights holders.

GitHub Pages publishes `main` from the repository root. All asset and page paths are relative
so both the project URL and its nested language/property routes work without a custom domain.
